# boss自动化插件

BOSS 岗位读取扩展与本地求职工作台。按批次整理完整 JD，对照个人简历匹配评分，并生成定制化招呼草稿。

## 功能

- 从当前岗位详情页导入，或从筛选后的职位搜索页批量读取。
- 按岗位链接跨批次去重，目标数量只统计成功新增的岗位。
- 可设置随机间隔和分段休息；详情读取、翻页及滚动加载都计入节奏控制，支持暂停、继续、停止。
- 每个批次拥有独立的岗位清单，按当前简历的匹配分降序排列。
- 支持本地规则分析，以及 DeepSeek 等 OpenAI 兼容模型服务。
- 生成简洁或详细招呼，附简历依据，保存审核结果和人工待投递队列。

工作台不会向招聘者发送消息。遇到 BOSS 安全验证时暂停，由用户自行处理；采集间隔不保证避免平台风控。

## 启动本地工作台

需要 Python 3.11 或以上版本；服务运行无需安装第三方 Python 包。

```sh
git clone https://github.com/m15383013399-commits/boss-auto-plugin.git
cd boss-auto-plugin
python3 run.py
```

打开 [本地工作台](http://127.0.0.1:8765/)。Mac 也可以双击 `启动工作台.command`，保留打开的终端窗口。按 Ctrl+C 停止服务；关闭网页不会停止后台服务。默认不开机自启。

首次启动为空工作区。到“简历与设置”导入 DOCX 或粘贴简历，填写求职偏好与模型服务配置。模型 API Key 在本机填写，不随代码提供。

## 安装 Chrome 扩展

1. 打开 Chrome 扩展管理页，开启“开发者模式”。
2. 点击“加载已解压的扩展程序”，选择本仓库的 `extension` 文件夹。
3. 在工作台复制本机连接密钥，到扩展的连接设置中粘贴并保存。
4. 登录 BOSS，在“职位”页面完成搜索和筛选，再打开扩展。
5. 单岗位模式先读取完整 JD，再确认导入。批量模式打开控制页，填写成功新增目标、间隔和分段休息设置后开始。
6. 运行期间保留 BOSS 页和控制页。返回工作台选择批次，开始匹配并查看岗位清单。

默认每次操作后随机等待 3–5 秒，每操作 10 次休息 60 秒，均可调整。详情读取、翻页或滚动加载各算一次操作，失败也计数；纯本地跳过重复岗位不计数。分段休息与当次间隔取较长值，详情加载时间另计。等待中可以暂停或停止，剩余等待时间及设置保存在扩展本机存储中。更新代码后重新加载扩展并重新打开控制页。

起点是当前页面已加载的卡片顺序，不仅限于屏幕内的卡片，也不会主动回到第一页。所有历史批次的已知链接在打开详情前跳过；连续重复页的加载同样受节奏限制。

进入某批次后，岗位列表、详情、搜索和状态筛选只显示该批次。通过“返回导入批次”选择另一批次。手动导入会新建独立批次。

## 模型配置及数据流

填写服务方提供的兼容 OpenAI API 地址、准确的模型名称和 API Key。支持 Base URL 或完整的 `/chat/completions` 地址。匹配和招呼生成会将相关 JD 与简历提交给你配置的模型服务；规则分析在本机完成。

模型按岗位职责、技能、行业、资格和加分项评估，并返回简历依据。匹配和招呼生成相互独立，修改简历后需要重新匹配。分数用于比较岗位；模型事实核验不能替代人工审核。

采集需要 BOSS 页面，匹配和生成草稿只需要本地服务及相应模型服务。数据在服务停止后仍保留。

## 本机私有文件

以下内容由程序运行时创建，不提交到 Git：

- `data/workspace.sqlite3`：简历、岗位、批次、评分和招呼草稿。
- `data/model.json`：模型 API 配置与 Key。
- `data/local-key`：本地工作台连接密钥。
- `.env`、简历文件、数据库备份和运行日志也已加入忽略规则。

模型 Key 在本机文件中保存，接口不会回传实际 Key。请勿强制添加这些被忽略的文件。

## 目录

- `app/`：本地服务、数据存储、简历解析、匹配和模型适配。
- `extension/`：Chrome MV3 扩展与采集控制页。
- `web/`：工作台页面。
- `tests/`、`extension/tests/`、`web/tests/`：使用虚构样例和本地模拟服务的测试。

仓库不包含真实简历、岗位数据库、浏览器登录资料、API Key 或个人开发记录。

## 验证

运行 JavaScript 测试需要支持 `node:test` 的 Node.js 版本。

```sh
python3 -m unittest discover -s tests
node --test extension/tests/*.test.mjs web/tests/*.test.mjs
```

Python 测试会在回环地址启动临时模拟服务；不需要真实模型 Key，也不访问 BOSS。页面读取依赖 BOSS 前端结构，站点更新后可能需要适配。
